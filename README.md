# Titanic Data Cleaning & Visualization Project

## Overview

This project focuses on cleaning, preprocessing, and visualizing the Titanic dataset using Python. The objective is to identify patterns, trends, and insights from the data while demonstrating essential data science skills such as handling missing values, removing duplicates, detecting outliers, and creating meaningful visualizations.

## Objectives

* Clean and preprocess raw data
* Handle missing values
* Remove duplicate records
* Detect and analyze outliers
* Perform exploratory data analysis (EDA)
* Visualize key findings using charts and plots
* Generate insights from the dataset

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

The dataset used is the Titanic Passenger Dataset, which contains information about passengers such as age, gender, passenger class, fare, and survival status.

## Data Cleaning Steps

1. Checked for missing values.
2. Filled missing values in relevant columns.
3. Identified and removed duplicate records.
4. Examined numerical columns for outliers.
5. Verified data quality before analysis.

## Visualizations

### 1. Survival by Gender

Shows survival distribution among male and female passengers.

### 2. Passenger Class vs Survival

Analyzes how passenger class affected survival rates.

### 3. Age Distribution

Displays the age distribution of passengers.

### 4. Fare Outliers

Uses a boxplot to identify extreme fare values.

## Key Insights

* Female passengers had a higher survival rate than male passengers.
* First-class passengers were more likely to survive than passengers in lower classes.
* Most passengers were between 20 and 40 years old.
* The fare column contained several outliers.
* Data preprocessing improved dataset quality for analysis.
